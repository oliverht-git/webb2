Webbens funktion

Webben fungerar med att det finns tre grundläggande komponenter av vilket alla är skapade av Tim burners-lee fadern av Webben.

Dessa tre komponenter som sakar webben som vi känner till idag är HTTP( Hypertext Transfer Protocol), HTML(hyper text markup language) och URL(uniform resource locator) de här tre komponenterna är vad som gör att vi idag kan använda webben än idag. Sen är det inte de ända sakerna som behövs för att ha igång webben utan webben behöver även en server där man laggrar webbsidornas filer. Som sedan blir omgjorda till en webb ip som är siffror ett exempel är 192.168.1.1 de här siffrorna är vad som användas för att komma in på en webbsida. Men för att inte behöva skriva in alla siffror varje gång du ska in på en webbsida så skapade det ett system som gör om siffrorna till en text tillexempel google.com detta system kallas för DNS (Domain name server).
